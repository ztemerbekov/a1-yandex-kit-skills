# Управляйте Яндекс KIT с помощью AI-ассистента

<img src="./assets/logos/a1-logo-warm.svg" alt="A1" width="22">&nbsp;**Yandex KIT Skills** <sup>β</sup> подключает магазин к привычному AI-приложению. Вы ставите задачу обычными словами, а ассистент читает фактические данные магазина и берёт рутинную работу на себя — не просто даёт общие советы.

- **Четыре готовых сценария.** Текущий контроль, аудит каталога, запуск промо и проверка магазина перед открытием.
- **Голосом или текстом.** После подключения рабочие задачи можно диктовать, если AI-приложение поддерживает голосовой ввод.
- **Изменения только по команде.** Проверки ничего не меняют, а цены, остатки, сроки и другие бизнес-значения ассистент не придумывает.
- **В привычном AI-приложении.** Отдельный интерфейс для работы с магазином не нужен.

## Что уже умеет ассистент

1. **Оператор** (`a1-yandex-kit-operator`) показывает текущий статус магазина и то, что требует внимания.
2. **Доктор каталога** (`a1-yandex-kit-catalog-doctor`) проверяет каталог целиком и применяет точные исправления.
3. **Запуск промо** (`a1-yandex-kit-promo-launcher`) запускает и изменяет скидки, промокоды и подарки по заданным условиям.
4. **Проверка запуска** (`a1-yandex-kit-launch-check`) проверяет, что мешает открытию магазина и какие участки ещё не подтверждены.

## Увидеть работу за минуту

> **Вы:** Что требует внимания в магазине за последние три дня?
>
> **Результат:** ассистент проверит доступные заказы, быстрый срез каталога, активные промо и вебхуки. Сначала покажет приоритетные пункты, затем факты, доступные действия и ограничения данных.

## Быстрый старт

### Установка

Для команды установки нужен [Node.js 20+](https://nodejs.org/). Setup-навык сам Node.js не устанавливает: без него нельзя сначала добавить пакет навыков. Если команда `npx` не запускается, установите Node.js и повторите шаг.

> **Важно.** Токен даёт полный доступ к магазину, хранится открытым текстом в пользовательском конфиге AI-приложения, а отправленный в чат токен останется в истории чата. Собственной песочницы нет: все действия выполняются в боевом магазине.

1. Откройте терминал. На Windows подойдут Windows Terminal, PowerShell или Command Prompt; на macOS и Linux — обычный терминал. Одна и та же команда работает во всех этих оболочках:

   ```bash
   npx skills@latest add ztemerbekov/a1-yandex-kit-skills -g -y
   ```

2. **Явно вызовите** установщик навыком `a1-yandex-kit-setup`. В Codex вызов выглядит так:

   ```text
   $a1-yandex-kit-setup
   ```

   В другом AI-приложении выберите навык с этим именем в списке команд.

3. Следуйте вопросам установщика. Он проверит окружение и токен, подключит магазин к выбранному приложению и выполнит первый вызов.

4. После сообщения об успешном подключении рабочие сценарии можно вызывать обычными фразами — голосом или текстом. Начните с простого вопроса:

   > Как дела в магазине?

**Что на выходе:** приоритетный разбор заказов, быстрого состояния каталога, промо и вебхуков за выбранный период. Каждый пункт опирается на факты из магазина; недоступные данные остаются явным ограничением.

<summary><strong>Доктор каталога — состояние каталога</strong></summary>

<br>

**Доктор каталога** (`a1-yandex-kit-catalog-doctor`) помогает поддерживать корректные карточки, цены и остатки, не открывая вручную каждый товар.

**Что на выходе:** полный read-only аудит выбранных областей с точным покрытием, найденными объектами и разделением на блокеры, риски и рекомендации. По отдельной точной команде навык исправляет одиночные или массовые значения из указанного пользователем источника.

> 💬 **Попробуйте спросить:**
>
> «Проведи полный аудит каталога» · «Поставь цену 4 990 рублей для SKU-42» · «Исправь остатки по этому файлу».

</details>

<details>
<summary><strong>Запуск промо — скидки, промокоды и подарки</strong></summary>

<br>

**Запуск промо** (`a1-yandex-kit-promo-launcher`) помогает запустить скидку, промокод или подарок точно на нужные товары и срок, не потеряв заданные условия при настройке.

**Что на выходе:** проверенные товары и существующие промо, выполнение разрешённой последовательности действий и повторное чтение итогового статуса. Механику, размер скидки, область действия, сроки, лимиты и статус задаёт пользователь; при нехватке условий запись не начинается.

> 💬 **Попробуйте спросить:**
>
> «Создай промокод WELCOME10 “Приветственная скидка”: 10% на заказ, с 1 по 7 августа 2026 года по Москве, лимит 100 использований, активный».

</details>

<details>
<summary><strong>Проверка запуска — готовность к открытию</strong></summary>

<br>

**Проверка запуска** (`a1-yandex-kit-launch-check`) помогает перед запуском убедиться, что покупатель сможет найти товар и пройти доступные этапы покупки без подтверждённых критических проблем.

**Что на выходе:** статус **«не готов»**, **«условно готов»** или **«готов»** с отдельными блокерами, рисками и непроверенными участками. Навык проверяет данные каталога и промо, подтверждения checkout, а при наличии web-доступа у AI-приложения — публичную витрину. Статус **«готов»** не ставится только по данным API.

> 💬 **Попробуйте спросить:**
>
> «Проверь, готов ли магазин к открытию».

</details>

## Как сохраняется контроль над изменениями

- Запросы **«покажи»**, **«проверь»**, **«разбери»** и **«найди»** выполняются без изменений.
- Для записи нужны однозначные цель, действие и значение. Ассистент не придумывает цену, остаток, срок, лимит, категорию или другое бизнес-решение.
- Точная команда считается разрешением на указанное действие. Отдельное второе подтверждение по умолчанию не запрашивается.
- Перед изменением ассистент читает нужный объект, а после — проверяет его фактическое состояние. Неоднозначная запись не повторяется автоматически.
- Для изменений в магазине не создаются резервные копии, снимки или собственный механизм отката.

## Важные границы

- У проекта нет песочницы и постоянного фонового мониторинга. Ассистент работает только тогда, когда вы ставите ему задачу.
- API не позволяет произвольно создавать и редактировать заказы, менять любые статусы оплаты и доставки, проводить возвраты или связываться с покупателем.
- Проверка запуска не видит настройки оплаты и доставки и не может сама создать и оплатить тестовый заказ.
- После таймаута или сетевой ошибки изменение может иметь неоднозначный результат. Ассистент проверит объект, если это возможно, но не будет повторять запись вслепую.
